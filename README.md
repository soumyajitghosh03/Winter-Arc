# ❄️ Winter Arc 2026

A full-stack personal habit, productivity, and daily-planning tracker built for the **Winter Arc 2026 challenge**.

Winter Arc is not just a habit tracker. The goal of this project is to create a simple system that helps me plan my days, track important habits, maintain consistency, and gradually improve my health, discipline, learning, and productivity throughout the 92-day Winter Arc.

---

## 🎯 Why I Built This

The idea behind Winter Arc came from a simple problem:

> It is easy to make plans. It is much harder to consistently execute them and look back at whether you actually did what you planned.

Most habit trackers focus mainly on checking boxes:

- Did you exercise?
- Did you meditate?
- Did you study?
- Did you read?

But my routine is more detailed than that.

I wanted a system where I could:

- Plan an entire day.
- Decide what I need to do and when.
- Record sleep.
- Track individual activities.
- Mark activities as completed or skipped.
- Plan tomorrow in advance.
- Edit previous days.
- Review my progress through a calendar.
- Maintain daily notes.
- Reuse common activities instead of creating them repeatedly.

Instead of using a generic productivity application, I decided to build my own system around the way I actually organize my days.

At the same time, this project gives me practical experience building a complete application from scratch using a real frontend, REST API, backend server, database, authentication-ready architecture, and cloud database.

---

# 🌨️ The Winter Arc

The challenge runs from:

**October 1, 2026 → December 31, 2026**

That is:

**92 days**

The main goals are:

- Fix and maintain a consistent sleep schedule.
- Improve food and health habits.
- Build consistency in DSA and Mathematics.
- Continue learning additional technical skills.
- Maintain productivity during office work.
- Read regularly.
- Practice meditation.
- Build discipline through consistent daily execution.

Some activities are permanent parts of my routine, while others can be planned differently depending on the day.

The application therefore treats every date as an independent workspace.
